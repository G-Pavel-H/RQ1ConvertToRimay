For each non-contact search by phone number, if the current user has a "US phone number", then Signal-Android shall find the "US phone number" when the user enters it with "+" and the calling code, with the calling code only, or without the calling code.
For each non-contact search by phone number, if the current user has a "US phone number", then Signal-Android shall find a "non-US phone number" when the user enters it with "+" and the calling code or with the calling code only.
For each non-contact search by phone number, Signal-Android shall try prepending the "calling code of the current user's phone number" and the "calling code of the default region of the current device" to the entered phone number.
