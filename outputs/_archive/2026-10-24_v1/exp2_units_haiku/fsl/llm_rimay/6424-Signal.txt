For all users with a US phone number, when the user searches for another US phone number, then the App must allow search by entering the full number, the number without the country code, or the number without the country and area codes.
For all users, when the user searches for a non-US phone number, then the App must allow search by entering the full number with country code or the number without the country code.
For all users, the App must try prepending both the calling code for the current user's phone number and the calling code that corresponds to the default region for the current device when performing phone number lookups.
