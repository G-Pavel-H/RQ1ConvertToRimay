When a user with a US phone number searches for another US phone number, the System shall enable search by entering the full number with country code, the number without country code, or the number without country code and area code.
When a user searches for a non-US phone number, the System shall enable search by entering the full number with country code or the number without country code.
When a user searches for a phone number, the System shall try prepending both the calling code for the current user's phone number and the calling code that corresponds to the default region for the current device.
