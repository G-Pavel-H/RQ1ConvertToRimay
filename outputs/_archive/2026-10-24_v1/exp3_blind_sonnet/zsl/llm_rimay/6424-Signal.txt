For a user with a US phone number, the Android application shall allow the user to search for another US phone number by entering the number in the format "+17043264096", "17043264096", or "7043264096".
For a user with a US phone number, the Android application shall allow the user to search for a non-US phone number by entering the number in the format "+441733530267" or "441733530267".
The Android application shall prepend the calling code of the current user's phone number when searching for a non-contact phone number.
The Android application shall prepend the calling code that corresponds to the default region of the current device when searching for a non-contact phone number.
