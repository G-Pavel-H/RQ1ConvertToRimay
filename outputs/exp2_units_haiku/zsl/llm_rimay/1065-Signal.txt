When the user sets the passphrase during the first start, then the System <MISSING_MODAL_VERB> request the user to specify the desired behaviour by choosing one of the following: "only use push", "use SMS fallback", or "use as default SMS/MMS-App".
When the System displays the behaviour selection options during first start, then the System <MISSING_MODAL_VERB> provide a "what does that mean?" button which opens a pop-up that explains in simple words what every mode does.
