For the Signal-Android search for non-contacts by phone number, the System shall have parity with the Signal-iOS search improvements for non-contacts.
For a user with a US phone number, when the user enters "+17043264096", "17043264096" or "7043264096" to search for another US phone number, then the System shall find the user with the phone number "+17043264096".
For the current user, when the user searches for a phone number, then the System shall try prepending the calling code of the current user's phone number and the calling code that corresponds to the default region of the current device.
